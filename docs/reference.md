# Flash DOM API Reference

This document provides the API reference for the Flash DOM library.

## Core Concepts

Before delving into the specific functions, it is helpful to understand the primary types and concepts used throughout the API.

- **Target**: The existing DOM element (or a CSS selector string that resolves to one) that you intend to update.
- **Source / Future**: The desired state you want the target to reflect. This can be expressed as a raw HTML string, a single DOM node, or an array of DOM nodes.
- **Patches**: An array of granular mutation instructions (such as text updates, attribute modifications, or node movements) generated by the diffing algorithm.

## flash

$flash: target, source \to \emptyset$

The `flash` function orchestrates the entire update process. It evaluates the provided `target`, parses or normalizes the `source`, computes the exact differences, and applies those updates in place. 

The function acts as a highly flexible entry point. If you pass a CSS selector string for the `target`, it queries the document for the corresponding element. If you provide an HTML string for the `source`, it utilizes native browser parsing to convert it into a DOM structure before computing differences.

### Example

```coffeescript
import { flash } from "@dashkite/flashdom"
import assert from "@dashkite/assert"

target = document.createElement "div"
flash target, "<h1>Hello</h1>"

assert.equal target.firstChild.tagName, "H1"
assert.equal target.firstChild.textContent, "Hello"
```

## diff

$diff: current, future \to patches$

The `diff` function calculates the structural, text, and attribute differences between the `current` node and the `future` node. 

Instead of generating a completely new Virtual DOM representation, this algorithm recursively inspects the actual child nodes and applies a similarity scoring threshold to identify the best candidates for reuse among siblings. This approach preserves existing DOM nodes wherever possible, minimizing expensive reflows. The function outputs a sequential array of patch instructions.

### Example

```coffeescript
import { diff } from "@dashkite/flashdom"
import assert from "@dashkite/assert"

current = document.createElement "div"
future = document.createElement "p"

patches = diff current, future

assert.ok Array.isArray patches
assert.ok patches.length > 0
```

## patch

$patch: patches \to \emptyset$

The `patch` function executes the array of operations generated by the `diff` function. It iterates through the sequence of patches, modifying the affected nodes in place to reflect the desired future state. 

This function provides the actual mutation phase of the library, isolating the side effects to a single execution pass.

### Example

```coffeescript
import { patch, diff } from "@dashkite/flashdom"
import assert from "@dashkite/assert"

current = document.createElement "div"
future = document.createElement "p"

patches = diff current, future
patch patches

assert.equal current.tagName, "P"
```
